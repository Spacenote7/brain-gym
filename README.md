# Brain Gym — 前頭葉ジム

前頭葉（前頭前野）の活性化とワーキングメモリ・記憶力の向上を狙った、1日10分の脳トレPWA。
依存ゼロの単一HTML。オフライン動作・iPhoneホーム画面追加に対応。

**公開URL: https://spacenote7.github.io/brain-gym/**（GitHub Pages / スコアは各端末内のみ、サーバー送信なし）

## 種目（5種）

| 種目 | 鍛える機能 | 設定できる項目 |
|---|---|---|
| Nバック | ワーキングメモリ | レベル(1〜3バック) / 速さ / 回数 |
| ストループ | 抑制機能・注意制御 | 問題数 / ひっかけ率 |
| 計算スピード | 処理速度（川島式） | 問題数 / 難易度3段階 |
| 数字スパン | 短期記憶 | 順唱・逆唱 / 開始桁 / 表示速度 |
| 顔と名前 | 人物記憶（顔・名前・プロフィール） | 人数(3/4/6) / 出題範囲 |

顔はSVGで手続き生成（外部画像・通信なし）。名前・職業・趣味をランダムに組み合わせ、
テストでは登場人物同士の名前を選択肢に混ぜて「顔と名前の取り違え」を検出する。

## ゲーミフィケーション（習慣化支援）

- **XP・レベル**: セッション完了でXP獲得。「ねぼけ脳」→「前頭葉マスター」まで10段階
- **実績バッジ**: 11種（連続日数・種目別ハイスコア・通算回数など）
- **連続日数ストリーク**: 1日1種目でも継続扱い（怠け者にやさしい設計）
- **今日はこれだけでもOK**: 未実施の種目を1つだけ提案するチップ

## 記録

- スコア・XP・実績・設定はすべて端末内の `localStorage`（外部送信なし）
- 「記録と実績」画面に種目別の直近10回バーチャートと実績一覧

## 開発

```sh
python3 -m http.server 8931  # Service Workerのためhttpで配信
```

更新をデプロイしたら `sw.js` の `CACHE` 版数を必ず上げること（インストール済みPWAへの更新配信に必要）。

## ロードマップ（ネイティブ化・収益化）

1. **現在**: PWA（GitHub Pages配信・無料・広告なし）
2. **次**: [Capacitor](https://capacitorjs.com/) でWebViewラップ → iOS/Androidネイティブアプリ化
   - コードはvanilla JS単一ファイルのまま流用できる（フレームワーク非依存を維持する）
   - AdMobプラグインでバナー/インタースティシャル広告 → 収益化
   - App Store配信にはApple Developer Program（年99ドル）が必要
3. **将来**: リマインダー通知（Capacitor Local Notifications）/ 記録のクラウド同期

## 構成

- `index.html` — アプリ本体（HTML/CSS/JS すべて込み）
- `manifest.json` — PWAマニフェスト
- `sw.js` — Service Worker（キャッシュ優先・オフライン対応）
- `icon-180.png` / `icon-512.png` — アイコン
