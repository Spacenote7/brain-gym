# Brain Gym — 前頭葉ジム

前頭葉（前頭前野）の活性化とワーキングメモリ・記憶力の向上を狙った、1日10分の脳トレPWA。
依存ゼロの単一HTML。オフライン動作・iPhoneホーム画面追加に対応。

## 種目（4種）

| 種目 | 鍛える機能 | 内容 |
|---|---|---|
| Nバック | ワーキングメモリ（前頭前野の代表課題） | 3×3マスの光る位置がN個前と同じなら押す。1〜3バック |
| ストループ | 抑制機能・注意制御 | 文字の意味を無視して「文字の色」で答える。20問 |
| 計算スピード | 処理速度（川島式） | 単純計算20問のタイムアタック |
| 数字スパン | 短期記憶・記憶力 | 数字列を覚えて再生。逆唱モードは前頭葉負荷が高い |

## 記録

- スコアは `localStorage` に端末内保存（外部送信なし）
- ホームに連続日数・今日の完了数・種目別ベスト
- 「記録を見る」で直近10回の推移バー

## 使い方

```sh
# ローカル起動（Service Workerのためhttpで配信する）
python3 -m http.server 8931
# → http://localhost:8931
```

iPhone: Safariで開いて「共有 → ホーム画面に追加」でフルスクリーンのアプリとして起動できる。

## 構成

- `index.html` — アプリ本体（HTML/CSS/JS すべて込み）
- `manifest.json` — PWAマニフェスト
- `sw.js` — Service Worker（キャッシュ優先・オフライン対応）
- `icon-180.png` / `icon-512.png` — アイコン
